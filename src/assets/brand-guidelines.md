## 一、品牌概述

**品牌名称**：光影视界 (Light Vision)

**品牌定位**：高端摄影分享平台，连接全球摄影爱好者，分享光影艺术之美

**核心价值**：捕捉瞬间，分享光影

---

## 二、Logo 系统

### 主 Logo

**设计理念**：融合光圈、无限符号与字母 "L"

```
┌─────────────────────────────────┐
│      ○──────○                  │
│     /        \                 │
│    │    L     │    Light Vision│
│     \        /                 │
│      ○──────○                  │
└─────────────────────────────────┘
```

**设计说明**：
- 圆形代表镜头光圈，象征摄影的核心工具
- 无限符号 ∞ 融入其中，代表无限创意与分享
- 中心字母 "L" 代表 Light Vision 的首字母
- 整体呈现优雅、现代的视觉感受

### Logo 变体

| 类型 | 用途 |
|------|------|
| 主 Logo | 网站首页、品牌宣传 |
| 简化版 | 移动端应用、图标 |
| 单色版 | 水印、灰度场景 |

## 四、排版系统

### 字体组合

| 层级 | 字体 | 字重 | 用途 |

| 标题 | Inter | 700 | 页面标题、品牌名称 |

## 五、视觉元素

### 纹理与质感

- **星点纹理**：背景装饰，营造摄影氛围
- **渐变光效**：用于按钮、卡片的悬停效果
- **毛玻璃效果**：导航栏、模态框

### 图标风格

- 线性图标为主
- 统一的圆角半径
- 24px 标准尺寸
